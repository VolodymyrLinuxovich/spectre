Spectre

AI agents run the experiments. Spectre tells you which gains are real.

Agents propose ways to identify molecules from mass spectra. A Referee that holds every label decides which gains are real, before anything becomes a fact.

See how a claim is judged Read the code

AI scientists find gains that aren't there.

Give an agent a benchmark and a score to raise, and it will raise it. Most of the time the reason is not the idea it reports.

4,000 of 4,000

The answer is already first

In MassSpecGym's raw candidate lists the true molecule sits at the top for every val spectrum. Return the list as given and hit@1 is 1.00.

±0.005

Seeds move the score

Retraining the same baseline on three seeds spreads MRR enough that any gain inside ±0.005 could be luck. One run cannot tell.

294 papers

Leaks look like progress

Data leakage has inflated results in at least 294 papers across 17 fields. Autoresearch loops make the same mistakes, only faster.

"These flaws are largely invisible at the level of the final manuscript." Luo, Kasirzadeh and Shah, PNAS 2026

A Referee they can't game.

Proposers never see a label. Every claim has to clear four checks in order. The first one it fails becomes its verdict, with the evidence attached.

Search before spending

Each proposer checks recent papers with Exa and skips ideas that were already tested.

Remember what failed

Verdicts go to shared memory on past.dev. Other agents read them and don't repeat them.

Run sealed

Agent code runs in a Modal sandbox with no network and no labels mounted.
